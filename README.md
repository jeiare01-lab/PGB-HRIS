# PGB HRIS Dashboard

**CMG Pilot (PSC, ABC, CSI) — Interactive 7-Tab Executive Dashboard**

## ⚡ Quick Start (2 Minutes)

```bash
npm install
npm run dev
```

Open browser: **http://localhost:3000**

---

## 📊 What You'll See

7 Interactive Tabs:

1. **📊 Executive Dashboard** — 180 employees, KPIs, Rocks alignment
2. **💼 Recruitment** — 15 open positions, time-to-fill, cost-per-hire
3. **⭐ Performance** — Rating distribution, compensation impact
4. **🎯 Talent & Succession** — High potentials, development plans
5. **📚 Training** — 20 programs, competency tracking
6. **🏥 OHSW** — Safety metrics, wellness, incident trending
7. **🛠️ Service Delivery** — SLA compliance, satisfaction
